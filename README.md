# Modelo Conceptual - Red Social Pascualina

Modelo Conceptual de la Red Social Pascualina

## Descripción del caso

Este proyecto está diseñado para representar una base de datos de una red social estudiantil, en la cual solo los estudiantes podrán interactuar de forma dinámica en eventos sociales, culturales y académicos, será moderada por estudiantes sin la participación de profesores o parte administrativa del pascual. tendrá por nombre red social pascualina.
